Bot Core — Message Path

How an inbound message reaches the LLM, and where the agent loop joins the same rails. Composition happens in BotManager; both engines share one prompt builder and one tool registry.

Two entry paths

Not every message is gated

  • Telegram goes through grammy handlers, so ConversationGate runs first (handler-registrar.ts:242).
  • BotManager.handleChannelMessage() is the channel-agnostic entry and delegates straight to the pipeline (bot-manager.ts:1355).

Why they're shared

One builder, one registry

  • Both are constructed once in BotManager and injected into each engine (bot-manager.ts:319–345).
  • That's what keeps conversation and agent-loop prompts from drifting apart.
